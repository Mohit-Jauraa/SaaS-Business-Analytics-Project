# SaaS Business Analytics and Churn Strategy

**Author:** Mohit Jaura  
**Role:** Business Analyst  

## Project Objective
This repository contains an end-to-end business analytics project focused on diagnosing revenue slowdowns, MRR contraction, and customer churn within a B2B SaaS environment. The goal was to move beyond basic visualization and conduct deep root-cause analysis to provide clear, actionable recommendations for company leadership.

## Tech Stack & Tools
* **Data Visualization & Modeling:** Power BI (Dax, Star Schema, Decomposition Trees)
* **Database Querying:** SQL 
* **Statistical Analysis:** Advanced Microsoft Excel
* **Workflow & Prompt Engineering:** Generative AI 

## Project Workflow & Documentation
This project was executed in sequential phases to mirror a real-world enterprise data pipeline:
1. **[GenP Business Exploration](1.GenAI_Business_Exploration.pdf):** Initial industry research and context mapping.
2. **[Framing Problem Statements](2.Framing_Problem_Statements.pdf):** Defining the core business questions to solve.
3. **[Sales Analysis Summary](3.Sales_Analysis_Summary.pdf):** Evaluating customer acquisition channels and financial health metrics.
4. **[SQL Query Results](4.SQLQuery_Results.pdf):** Extracting and transforming raw database information.
5. **[Statistical Analysis](5.Statistical_Analysis.pdf):** Identifying correlations between support ticket response times and customer churn.
6. **[Final Executive Summary](6.Executive_Summary.pdf):** The final strategic memo prepared for leadership.
7. **[Power BI Dashboard](GEN_P_BI_DASHBOARD.pbix):** The interactive `.pbix` file featuring a relational data model and root-cause analysis trees.
                        
## Key Executive Insights
* **Targeting Misalignment:** Analysis showed that referral partners were overselling enterprise software packages to small businesses, resulting in a high cancellation rate in that segment.
* **Support Friction:** Mid-market customers were found to submit the highest volume of support tickets while simultaneously driving the highest revenue contraction, pointing to a need for better onboarding.
* **Proactive Retention:** Data revealed a direct link between low customer satisfaction scores and immediate monthly churn risk, highlighting the need for a faster support intervention system.
